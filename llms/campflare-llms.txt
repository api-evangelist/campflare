# Campflare

> Campflare provides real-time campground availability data and cancellation alerts for
> public campgrounds across North America. It tracks campsites at the individual-site level
> across every major public reservation system, and notifies consumers — by webhook for API
> users, by text/email/push for app users — the moment a matching site opens up. Campflare
> is operated by Vay Technologies LLC. The consumer product is free and ad-free; the data
> API is free for individuals and non-profits, and requires a paid license for commercial
> use.

## Access

The Campflare API is currently invite only. Request access at contact@campflare.com;
Campflare states invites are typically issued within 24 to 48 hours. Reasonable attribution
to Campflare is required wherever its data appears in a consuming application.

Because access is gated, Campflare publishes no OpenAPI, no GraphQL SDL, no AsyncAPI, no
Postman collection and no reference documentation beyond the prose product page below. An
agent cannot call this API without first obtaining an invite.

## API

- [API and Data](https://campflare.com/api): The developer page. Describes the four data
  products, the licensing terms, and the invite process. This is the only public API
  documentation Campflare publishes.
- API host: https://api.campflare.com — root returns `Campflare API :)`; the current
  version root https://api.campflare.com/v2 returns `{"name":"Campflare API v2"}`.
- Versioning: URI path, `https://api.campflare.com/v{major}`. Both v1 and v2 are monitored
  as live components on the status page.

## What the API offers

- Campground data: core details, amenities (hookups, facilities, accessibility), status,
  official agency alerts and notices, descriptions, attributed high-resolution photos,
  precise location data and driving directions, per-campsite characteristics and vehicle
  specifications, and cell-service coverage by major carrier.
- Availability: real-time availability for every tracked campground, broken down to the
  individual campsite.
- Availability alerts: create alerts against specific dates, campgrounds and campsite
  requirements, and receive a webhook callback when a matching site becomes available.
- Map layers: served from a CDN — topographic maps, public-lands boundaries (BLM, USFS,
  NPS), cell service, and more.
- Other data: queryable NWS, USFS and NPS alerts; public-land boundaries; a cell-service
  API; park descriptions.
